# 📝 Modern To-Do List Application

A sleek and functional task management application built with Vanilla JavaScript, featuring a responsive design and full CRUD (Create, Read, Update, Delete) capabilities.

## 🚀 Features
* **Add Tasks**: Quickly add new items to your list.
* **Edit Tasks**: Inline editing functionality to update existing tasks dynamically.
* **Task Completion**: Toggle tasks as completed with visual feedback (strikethrough and checkmark).
* **Delete Functionality**: 
    * Remove individual tasks.
    * **Clear All**: One-click button to wipe the entire list for a fresh start.
* **Responsive UI**: A beautiful, centered interface with a purple gradient background and smooth hover effects.

## 🛠️ Technologies Used
* **HTML5**: For the application structure.
* **CSS3**: 
    * Flexbox for layout alignment.
    * Linear gradients and box-shadows for a modern look.
    * Transition effects for interactive buttons.
* **JavaScript (ES6)**: 
    * Array-based state management to store tasks.
    * DOM Manipulation to render tasks dynamically.
    * Event Listeners for handling user interactions like "Enter" key detection.

## 📂 File Structure
* `TO-DO.html`: Contains the layout and the core JavaScript logic.
* `TO-DO.css`: Contains the styling and visual effects.
